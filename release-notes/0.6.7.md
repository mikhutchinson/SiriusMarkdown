# SiriusMarkdown 0.6.7

SiriusMarkdown 0.6.7 is the compiler-portable follow-up to `0.6.6`. The
`0.6.6` tag remains immutable; this release carries the same block-style API,
GitHub-inspired preset, atomic inline attachments, expanded native math corpus,
cache correctness, serializer, and concurrency hardening.

## Fixed

- A clean-checkout GitHub Actions build failed because the runner's Swift
  toolchain could not type-check a chained lazy `filter`/`map`/`min` expression
  in the vendored SwiftMath custom-symbol registry within its complexity
  budget. The lookup is now an explicit single-pass loop.
- Runtime behavior is unchanged: when a custom symbol override moves away from
  a nucleus, the registry restores the shortest remaining symbol name and uses
  lexicographic order to break equal-length ties.

## Included from 0.6.6

- Fourteen per-block style protocols and the opt-in
  `MarkdownRendererConfiguration.gitHub` preset.
- Atomic CoreText attachment placement for policy-allowed images, with bounded
  metrics, source-backed selection, and one AppKit/UIKit host per attachment.
- A shared 50-case native/KaTeX/MathJax math corpus and broader generated-LaTeX
  compatibility.
- Exact renderer cache identity, native fallback glyph shaping, finite math and
  attachment geometry, synchronized SwiftMath registries/font tables, robust
  public atom models, recursive table finalization, and non-mutating,
  color-preserving LaTeX serialization.

## Verification

- 850 Swift tests across 17 suites.
- Focused AddressSanitizer and ThreadSanitizer runs.
- Clean SwiftPM consumer build and three production demo bundles.
- 50-case math corpus, 27 Pretext fixtures, DocC/symbol graphs, performance
  budgets, and offscreen AppKit visual probes.
