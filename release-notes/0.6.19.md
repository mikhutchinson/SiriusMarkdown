# SiriusMarkdown 0.6.19

SiriusMarkdown 0.6.19 fixes a prepared-table containment bug that could let a
narrow cell's final wrapped line cross a row divider or be covered by the next
row.

## Fixed

- Prepared table header and body-row minimum heights are now resolved from the
  final column widths, theme padding, prepared line metrics, and atomic inline
  layout before SwiftUI measures or caches the row.
- Stable completed rows reuse their prepared heights incrementally while a
  mutable table grows. Column-width revisions use the cheap prepared-layout
  path and do not parse, highlight, or remeasure raw Markdown.
- Deliberately unprepared tables and custom table-cell styles stay on uncached
  natural measurement, preventing default-style geometry from being reused
  across incompatible view trees.
- The original finite user-bubble fixture now has exact prepared-height and
  offscreen pixel-containment regressions across CoreText-painted,
  prepared-native, system-text, and AppKit-selection modes.
- The Table Stress demo includes the same fixture for manual inspection at a
  narrow width, after horizontal scrolling, and in a wide window.

## Validation

The visual-enabled release gate passes all 939 Swift tests, the live 120-row
AppKit host and 500-row near-linear scaling budgets, a clean external SwiftPM
consumer build, all three bundled demos, the math corpus, every Pretext golden,
symbol graphs, warning-clean DocC, and the AppKit renderer probes.

The release retains the sanitized native rich HTML, bounded decorated-link
resolver, baseline corrections, native selection, streaming preparation, code,
math, Mermaid, attachment, and safe-policy behavior from 0.6.18.
