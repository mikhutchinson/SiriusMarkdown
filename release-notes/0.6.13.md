# SiriusMarkdown 0.6.13

SiriusMarkdown 0.6.13 fixes the remaining parser/preparation stalls observed
during very large live generations. Markdown semantics, tables, highlighting,
math, Mermaid, source-backed selection, and native macOS selection remain
fully enabled.

## Fixed

- AST source-range conversion now builds one UTF-8 line-start index per
  `swift-markdown` parse boundary. Blocks, lists, table cells, and inline runs
  resolve their source locations through the index instead of rescanning the
  growing mutable tail from byte zero for every node.
- `MarkdownRenderSession` now starts its parse/highlight/prepare pump from a
  detached user-initiated task. Only queued-operation drain and prepared-value
  publication hop to MainActor, so expensive preparation cannot inherit a
  SwiftUI caller's actor or task-local context.

## Verification

- A generated mutable-tail table with 120 rows parses in 25.63 ms; 960 rows
  parse in 205.62 ms, an 8.02x increase for 8x data. The release regression
  rejects ratios at or above 20x.
- A controlled replay of the pre-fix source-location converter did not finish
  the same test after 30 seconds; the fixed test completes in 0.88 seconds.
- A slow-highlighter regression records thread and task-local context and
  keeps a MainActor heartbeat live. It fails under inherited `Task` and passes
  only when preparation originates from the detached executor boundary.
