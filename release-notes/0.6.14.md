# SiriusMarkdown 0.6.14

SiriusMarkdown 0.6.14 carries the full long-generation performance work from
0.6.13 and makes its detached render pump strict-concurrency clean across the
supported Swift 6 toolchains. Markdown semantics, tables, highlighting, math,
Mermaid, native macOS selection, and exact source-backed selection remain fully
enabled.

## Fixed

- The detached `MarkdownRenderSession` pump no longer sends a task-isolated
  weak session reference into nested MainActor closures. It strongly owns the
  globally isolated session for one bounded operation drain and calls explicit
  MainActor batch/publication methods.
- The task clears its stored handle before returning, deterministically
  breaking the temporary retain cycle without moving parse, highlight, math,
  Mermaid, or inline preparation back to MainActor.

## Included performance fixes

- One UTF-8 line-start index per `swift-markdown` parse boundary replaces
  per-node source-prefix scans. The generated table regression remains 8.02x
  time for 8x rows; the restored pre-fix scanner did not complete in 30 seconds.
- Render preparation still originates on the detached user-initiated executor.
  The slow-highlighter regression proves it runs off the main thread without
  inheriting caller task-local context while a MainActor heartbeat stays live.
