# SiriusMarkdown 0.6.15

SiriusMarkdown 0.6.15 removes the remaining whole-document layout
amplification during long live generations. It keeps the complete renderer:
Markdown semantics, tables, highlighting, math, Mermaid, links, attachments,
copy, native macOS selection, and exact source-backed document selection all
remain enabled.

## Fixed

- The streaming SwiftUI surface now groups prepared items into bounded stable
  regions. Sealed regions cache their size by proposal width and revision;
  only the region containing the mutable tail invalidates as content arrives.
- Height publication is asynchronous and coalesced. The package no longer
  depends on `LazyVStack`'s private item-phase cache or a synchronous
  whole-document fitting loop for the streaming path.
- Active, unsealed inline/code/math/Mermaid values bypass caches intended for
  stable prepared content, preventing historical tail generations from
  displacing sealed entries.
- A bounded shared CoreText measurement cache reuses unchanged glyph widths
  across preparation values with full font and presentation identity.
- Plain and Highlight.js-backed highlighters process appended suffixes while a
  fence is active. The pinned Highlight.js wrapper forwards its real parser
  continuation, so open comments and strings match full-document output.
  Full-context checkpoints run every 16 KiB and every fence receives a full
  highlight on seal. Native Swift and custom highlighters keep their
  full-document contract where no proven continuation is available.
- Diagnostics now record highlighted byte volume so append scaling remains
  directly observable.

## Evidence

- The AppKit-hosted stress regression publishes a 179 KB prepared document 90
  times and measures mutable-tail layout at a 2.71 ms median.
- Regressions cover bounded region invalidation, persistent hosting-root
  replacement, incremental highlighting with full seal correctness, and
  cross-measurer CoreText width reuse.
- The serial Swift suite discovers and passes 881 tests.

There is no WebKit fallback and no selection, syntax, math, Mermaid, table, or
attachment downgrade in this release.
