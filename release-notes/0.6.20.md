# SiriusMarkdown 0.6.20

SiriusMarkdown 0.6.20 makes live GFM table work stay bounded through parsing,
preparation, and SwiftUI rendering, fixes native attachment serialization, and
replaces weak renderer tests with observable behavioral checks.

## Improved

- Unchanged table-cell render models are reused across mutable-tail reparses
  from a bounded cache. The table block's aggregate inline compatibility view
  is derived from those semantic cells instead of converting the AST twice.
- Default table cells carry exact width-specific line layouts, CoreText paint
  plans, and row heights into SwiftUI. Stable groups of completed rows use
  explicit render tokens and cached natural sizes so a growing suffix does not
  trigger triangular body evaluation and measurement work.
- Table diagnostics now expose model conversions and hits, row-group body
  evaluations/comparisons/reuse, preparation, width scans, and layout cache
  behavior for regression budgets.
- Transparent attachment placeholders and tinted math attachments use bounded
  bitmap-backed images that TextKit and ImageIO can serialize safely.

## Test quality

- Construction-only document, streaming, custom-table, ragged-table, code,
  math, and Mermaid checks now mount real AppKit view graphs and verify layout,
  painted output, or the absence of forbidden body-time preparation work.
- Pasteboard tests verify exact plain-text and Markdown representations and
  prove that omitted RTF/HTML types do not leak from an earlier copy.
- Controlled document-surface coverage now toggles the external binding in a
  mounted host and proves content visibility changes without repreparing.
- Streaming performance probes report the full pipeline/view-graph settle and
  explicit layout separately, with realistic watchdogs. Table preparation
  scaling compares 120-row and 500-row publication sequences directly.
- Release tooling no longer enables the expensive visual probes implicitly;
  `SIRIUS_MARKDOWN_RUN_VISUAL_PROBES=1` remains the explicit release option.

## Validation

The visual-enabled product gate passes all 941 Swift tests, including the live
120-row AppKit table and 500-row near-linear preparation budgets. It also builds
a clean external SwiftPM consumer, bundles all three demos, checks the 50-case
math corpus and all 27 Pretext fixtures, audits npm dependencies, generates
symbol graphs and warning-clean DocC, and passes the AppKit renderer probes.

The release preserves the sanitized native rich HTML, bounded decorated-link
resolver, stable streaming identity, native selection, code highlighting,
math, Mermaid, attachment, overflow, and safe-policy contracts from earlier
releases.
