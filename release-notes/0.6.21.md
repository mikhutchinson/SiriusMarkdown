# SiriusMarkdown 0.6.21

SiriusMarkdown 0.6.21 fixes stale streaming-region height after a mounted
prepared response reflows from a wide width to a substantially narrower width.

## Fixed

- `StreamingMarkdownView` no longer retains a provisional height measured at a
  new proposal width before descendant prepared inline layout has caught up.
- Prepared inline leaves publish a compact settled-layout generation only
  inside bounded streaming regions. When a width-specific `layoutResult`
  changes, the region rejects stale geometry reports, invalidates its
  width-cache generation, and remeasures to the new natural height.
- The fix preserves prepared view identity and selection state. It does not
  remount Markdown, clip overflow, add compensating padding, or estimate text
  height outside SiriusMarkdown.

## Regression coverage

The mounted AppKit regression keeps one `NSHostingView` and one
`StreamingMarkdownView` alive above a sentinel while changing its width from
420pt to 180pt. Paragraph, link, and list content exercises the prepared
CoreText line path. The test verifies that:

- prepared visual lines increase from 7 to 18;
- the reported streaming height grows from 170pt to 428.5pt;
- the sentinel begins at the streaming region's final bottom edge;
- every prepared CoreText surface stays above the sentinel; and
- the CoreText surface object identities remain unchanged.

## Validation

The release gate discovers and passes all 942 Swift tests, including the live
resize regression and existing long-transcript and 120-row table performance
budgets. It also builds a clean external SwiftPM consumer, bundles all three
demos, checks the 50-case math corpus and all 27 Pretext fixtures, generates
symbol graphs, and performs warning-clean DocC conversion. The visual-enabled
product gate additionally runs the offscreen AppKit RenderProbe.

The release preserves native SwiftUI block rendering, CoreText-painted
prepared-line inline rendering, stable streaming identity, sanitized native
rich HTML, safe policies, native selection, code highlighting, math, Mermaid,
attachments, and Pretext-backed layout.
