# SiriusMarkdown 0.6.9

SiriusMarkdown 0.6.9 is the AppKit-portable follow-up to `0.6.8`. It carries
the same native macOS selection and standard contextual-menu behavior while
fixing image-backed inline math on the newer AppKit version used by GitHub's
macOS runner.

## Fixed

- Math attachments now create an empty `NSTextAttachment` and explicitly
  assign their prepared image, baseline-adjusted bounds, and package-owned
  baseline cell. This avoids newer-AppKit normalization of
  `NSTextAttachment(data:ofType:)`. The image and bounds form the portable
  geometry contract; the bounded cache retains the legacy cell for older
  AppKit versions that use it.
- The release regression now requires the rendered image and exact
  baseline-adjusted bounds, and validates the custom cell when AppKit preserves
  it.
- `0.6.8` remains an immutable historical release; `0.6.9` is the clean
  fix-forward package version.

## Included from 0.6.8

- Bounded AppKit text leaves own default macOS selection, continuous wrapping,
  Copy, keyboard behavior, and the standard secondary-click menu.
- Image-backed inline math, prepared images, Mermaid ASCII, and math text
  fallbacks preserve semantic selection, copy, accessibility, and streaming
  identity without mounting SwiftUI's private selection overlay.
- Exact-source cross-block Markdown selection remains an explicit mode with one
  document-level menu owner.

## Verification

- 859 Swift tests across 17 suites.
- Full product gate: clean consumer resolution, three production demo bundles,
  math and Pretext corpora, DocC/symbol graphs, performance checks, and
  offscreen AppKit render probes.
- Focused AddressSanitizer coverage for native selection and attachment
  lifecycle paths.
