# SiriusMarkdown 0.6.23

SiriusMarkdown 0.6.23 carries forward the 0.6.22 renderer fixes and calibrates
the release gate's mounted streaming-table watchdog across supported runners.

## Fixed

- Every policy-authorized destination that normalizes into an activatable URL
  receives the immediate native globe glyph, including relative, scheme-less,
  and non-HTTP safe destinations.
- Transparent and effectively invisible public HTTPS favicon payloads cannot
  replace that visible fallback.
- Tight public theme line heights use the configured CoreText profiles'
  typographic minimum, keeping `p`, `g`, and `q` descenders visible across
  prepared, painted, and AppKit-selection text.
- The honest 120-row append-to-render benchmark now allows 1.5 seconds of
  GitHub-hosted arm64 wall-clock variance. Its exact incremental work counts,
  cache-reuse assertions, and sub-16 ms explicit-layout budget remain unchanged.

## Regression coverage

- Markdown links and sanitized HTML anchors share fallback behavior for
  relative and non-HTTPS destinations.
- Mounted AppKit tests cover fallback pixels and tight-line-height descenders
  in both prepared inline rendering modes and both macOS selection modes.
- Resolver tests reject effectively invisible decoded icons.
- The mounted 120-row table test continues to assert bounded model conversion,
  cell preparation, row evaluation, row measurement, and cache reuse in
  addition to the end-to-end watchdog.

## Validation

The release gate discovers and passes all 948 Swift tests. It also builds a
clean external SwiftPM consumer, bundles all three demos, checks the 50-case
math corpus and all 27 Pretext fixtures, generates symbol graphs, and performs
warning-clean DocC conversion. The visual-enabled product gate additionally
runs the offscreen AppKit RenderProbe.
