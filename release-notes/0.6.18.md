# SiriusMarkdown 0.6.18

SiriusMarkdown 0.6.18 is the cross-scale rendering patch for the native rich
HTML and decorated-link release introduced in 0.6.17.

## Fixed

- The default task-list square now includes a half-point optical baseline
  correction prepared from the active paragraph metrics. It stays centered on
  capital text in CoreText-painted, SwiftUI system-text, and native AppKit
  selection modes across compact, document, and larger type themes.
- The pixel regression now creates explicit 1x and 2x bitmap targets instead
  of inheriting the developer display's backing scale. This reproduces the
  standard-scale GitHub runner locally and prevents Retina-only success from
  masking a 1x alignment miss.
- The correction remains precomputed with renderer configuration; it adds no
  font measurement or other expensive work to SwiftUI `body` evaluation.

## Retained from 0.6.17

- Standards-aware, sanitized native rich HTML for the documented block and
  inline subset, with source-backed selection, copy, accessibility, stable
  identity, and policy-governed links and images.
- Package-owned decorated links with an immediate native fallback glyph and a
  replaceable, bounded, anonymous runtime favicon resolver. No bundled
  per-site table, favicon proxy, WebKit renderer, or default remote-image load
  is introduced.
- Mutable-table reuse, baseline/attachment fixes, AppKit subscript and
  superscript restoration, the three bundled HTML demonstrations, and the
  937-test release suite.

The full product gate covers explicit 1x/2x marker rendering, all 937 Swift
tests, performance budgets, bundled demo builds, a clean SwiftPM consumer,
Pretext and math-corpus checks, symbol graphs, warning-clean DocC, and AppKit
visual probes.
