# SiriusMarkdown 0.6.24

SiriusMarkdown 0.6.24 fixes live fallback-to-favicon replacement and link
wrapping in narrow prepared table cells, and refines the automatic first-paint
link cue for Apple text surfaces.

## Fixed

- Fixed-width prepared leaves now render the latest immutable inline layout
  after asynchronous metadata refresh instead of retaining fallback-era UTF-8
  byte ranges in SwiftUI state. The exact four-column mounted regression keeps
  the complete link label and mounts the resolved favicon.
- CoreText line-plan reuse now includes the complete prepared-content
  fingerprint, so different decoration content cannot reuse a same-geometry
  plan.
- Link decoration, nonbreaking spacer, and the first label token stay in one
  prepared wrapping unit. A template symbol or resolved favicon no longer ends
  a line by itself.
- `.automatic` now uses a decorative template SF Symbol sized with the
  surrounding text up to the configured maximum. Resolved branded favicons
  reuse the same reserved box and host without tinting. Direct
  `MarkdownLinkDecorationConfiguration` construction still supports custom
  text glyphs and fixed icon sizes.

## Regression coverage

- A mounted AppKit four-column table transitions from the longer custom glyph
  fallback to a shorter favicon attachment and verifies the full label, valid
  lines, attachment gap, and host.
- Layout tests force the former decoration-only line break and require the first
  label token to remain with it.
- Template-symbol tests cover compact 14-point metrics, light and dark
  appearances, native selection enabled and disabled, decorative accessibility,
  same-host replacement, and untinted branded pixels.
- A cache test proves equal line geometry cannot hide changed prepared content.

## Validation

The release gate discovers and passes all 954 Swift tests. It also builds a
clean external SwiftPM consumer, bundles all three demos, checks the 50-case
math corpus and all 27 Pretext fixtures, generates symbol graphs, and performs
warning-clean DocC conversion. The visual-enabled product gate additionally
runs the offscreen AppKit RenderProbe.
