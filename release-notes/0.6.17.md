# SiriusMarkdown 0.6.17

SiriusMarkdown 0.6.17 adds sanitized native rich HTML and package-owned
decorated website links while preserving the renderer's streaming-first,
prepared-model architecture. There is no WebKit rendering path and no favicon,
HTML, or image work in SwiftUI `body` evaluation.

## Native rich HTML

- Authorized HTML is parsed and normalized through SwiftSoup into source-mapped
  native block, inline, table, code, link, and attachment models.
- The supported subset includes headings, paragraphs and containers, block
  quotes, ordered and unordered lists, preformatted code, thematic breaks,
  tables, strong/emphasis/strikethrough/code, line breaks, subscript,
  superscript, spans, anchors, and policy-approved images.
- Markdown links and HTML anchors share the same destination policy,
  activation, accessibility range, link decoration, and preparation pipeline.
- Scripts, event behavior, embedded browsing/plugin content, active controls,
  arbitrary styles, and unsupported browser media remain inert. Remote images
  are still denied unless a host explicitly supplies an allowing policy and
  resolver.
- Static and streamed HTML use the same sanitizer and native conversion path;
  source-backed selection, copy, accessibility text, and stable identities are
  preserved.

## Decorated website links

- Every eligible link can paint an immediate native fallback glyph and later
  upgrade in place to a validated site icon without changing link identity,
  source mapping, activation, or the whole document model.
- The replaceable default resolver discovers declared icons, conventional
  favicon and Apple touch-icon paths, and qualifying declared square social
  artwork. It contains no bundled per-site asset/path table and uses no favicon
  proxy.
- Discovery uses anonymous ephemeral requests with no ambient credentials,
  cookies, or referrer. Navigation-scoped cookies may exist only inside the
  same anonymous redirect chain.
- Every hop is checked against public-origin and DNS policy, including the
  actual contacted socket endpoint. Redirects, candidates, response bytes,
  MIME types, decoded dimensions/frames, concurrency, total time, and
  positive/negative origin caches are bounded. In-flight work is coalesced.
- A curated live audit through the package resolver produced real icons for
  124 of 125 popular public domains. Nature's anti-bot response failed icon
  validation and correctly retained the safe native fallback. This live audit
  is compatibility evidence, not a deterministic network release gate.
- Fully decorated link leaves may omit redundant label underlines because the
  glyph is a non-color cue. Mixed decorated and undecorated leaves retain
  conventional underlines; color, focus, pointer, activation, and accessibility
  semantics are never removed.

## Rendering and streaming fixes

- Fixed ordered-list numerals, task squares, favicon bitmaps, and atomic inline
  attachments using inconsistent baselines across prepared CoreText and native
  AppKit rendering.
- Fixed AppKit native selection losing the scaled font and signed baseline
  offset for HTML subscript and superscript after attribute-scope conversion.
  The common no-script path uses a precomputed flag and performs no attributed-
  run scan.
- Fixed unequal-height table cells producing short dividers.
- Mutable GFM tables now retain source-stable completed rows and cells, update
  column maxima from changed cells, use bounded streaming width revisions, and
  reuse a bounded cross-publication row-measurement cache. Partial tail cells
  remain visible and sealed output remains one-shot-equivalent.

## Demo and evidence

- The bundled Markdown demo includes Native Rich HTML, an exhaustive HTML
  Element Gallery, and an HTML Safety and Media boundary. The galleries show
  every documented element, decorated anchors, allowed and denied image-policy
  outcomes, sanitizer diagnostics, and inert active/unsupported content.
- The serial release suite discovers 937 tests covering HTML semantics and
  sanitization, source/entity mapping, streamed equivalence, resolver security
  and caching, decorated-link rendering, native selection, baselines, mutable
  tables, scaling, and long-transcript performance.
- The release gate also builds the package and bundled demos, resolves and
  builds a clean SwiftPM consumer, runs Pretext golden and math-corpus checks,
  generates symbol graphs, converts warning-clean DocC, and runs the opt-in
  AppKit render probes.

This release does not add browser-executed HTML, inline HTML5 video/audio,
arbitrary CSS, default remote-image loading, or a WebKit fallback.
