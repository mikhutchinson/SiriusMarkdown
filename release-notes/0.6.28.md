# SiriusMarkdown 0.6.28

Hosts can now place a single native Find bar outside their scrolling Markdown
content using `documentFindController(_:showsInlineControls: false)` on
`StreamingMarkdownView` and the existing public `MarkdownDocumentFindBar`.

Find indexing, match highlighting, next/previous navigation, fragment links and
native scroll reveal remain active. Hosts own presenting Find, including Cmd-F,
when inline controls are hidden. The existing one-argument modifier keeps its
current behavior.

This is a general-purpose presentation API. It introduces no host-app routing,
private application types, parsing changes or new network behavior.

## Validation

The local product gate passed: 1,074 serial Swift tests, the clean public-API
consumer, all three bundled demos, math corpus, Pretext fixtures, symbol graphs,
DocC and focused product checks. Mounted navigation tests cover inline and
external controls, a single fixed Find field, selection and scroll reveal.

Standalone pixel-probe artifacts were not regenerated for this presentation API
change. Existing consumers retain the default inline controls.
