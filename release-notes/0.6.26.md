# SiriusMarkdown 0.6.26

SiriusMarkdown 0.6.26 makes asynchronous link-decoration replacement
destination-correct and adds bounded native rendering for HTML table spans.

## Link metadata and decoration

- Equal-geometry globe and favicon attachments now have distinct presentation
  fingerprints without invalidating reusable line or table measurements.
- Metadata completion reprepares only top-level blocks containing changed
  destinations instead of discarding the full prepared snapshot.
- Custom resolvers are scheduled per destination, while resolver-owned origin
  coalescing remains available. Cleared or expired negative cache entries can
  be retried by the same render session.
- Manual redirect validation aggregates contacted public endpoints across every
  request in the chain.
- A multiline semantic link receives one decoration even when its source
  contains authored soft or hard breaks.

## Native HTML tables

Authorized HTML `colspan` and `rowspan` values now participate in bounded
logical column placement, natural-width constraints, width-specific inline
layout, combined row heights, border segmentation, native SwiftUI rendering,
and source-backed selection geometry. Malformed spans are capped before they
become renderer structure. The AppKit RenderProbe includes a real table with
both span forms.

## Recursive native containers

Markdown and authorized HTML block quotes and list items now retain native
child blocks in source order. Nested fenced code, tables, quotes, paragraphs,
and mixed list kinds go through the same prepared renderer, policy, overflow,
selection, copy, and link-metadata paths as top-level blocks. Existing public
initializers and legacy list-only child fields remain available.

## Validation

The serial release floor is 966 Swift tests. New coverage includes mounted
same-geometry globe-to-favicon replacement, selective metadata diffing,
destination-scoped custom resolvers, cache-clear retry, redirect endpoint
aggregation, multiline links, span layout/selection/bounds, and a real offscreen
AppKit span artifact. Recursive-container coverage includes 80 streamed-versus-
static chunk sizes, nested link refresh, sanitized HTML, mounted style-slot
invocation, selection geometry, and a dedicated AppKit artifact. The full gate
also builds a clean external SwiftPM consumer, bundles all three demos, checks
the math corpus and Pretext fixtures, generates symbol graphs, and converts
DocC.
