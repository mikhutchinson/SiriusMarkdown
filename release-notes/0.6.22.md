# SiriusMarkdown 0.6.22

SiriusMarkdown 0.6.22 restores a visible native decoration for every allowed
activatable link, prevents transparent site icons from replacing that
fallback, and keeps glyph descenders visible under tight custom line heights.

## Fixed

- Every policy-authorized destination that normalizes into an activatable URL
  now receives the immediate native globe glyph, including relative,
  scheme-less, and non-HTTP safe destinations.
- Public HTTPS favicon discovery remains a separate remote-resource decision.
  Links that are ineligible for discovery retain their local glyph and do not
  schedule metadata resolution.
- The default metadata resolver now performs a bounded native visibility sample
  after validating icon bytes, type, frame count, and dimensions. Transparent
  and effectively invisible images are rejected, leaving the visible fallback
  in place.
- Requested public theme line heights now retain the configured value when it is
  large enough and otherwise use the configured CoreText profiles' cached
  typographic minimum. This prevents `p`, `g`, and `q` descenders from being
  clipped in prepared, painted, and AppKit-selection text.

## Regression coverage

- Markdown links and sanitized HTML anchors share the same fallback behavior
  for relative and non-HTTPS destinations.
- Mounted AppKit tests verify painted fallback pixels in both prepared inline
  rendering modes and both macOS selection modes.
- A mounted 2x AppKit regression compares ordinary text with `pgq` in those
  same four native-text paths and proves the descenders extend below the
  x-height without crossing the leaf frame.
- Resolver tests prove that valid visible icons are accepted while an
  effectively transparent decoded icon cannot replace the fallback.

## Validation

The release gate discovers and passes all 948 Swift tests. It also builds a
clean external SwiftPM consumer, bundles all three demos, checks the 50-case
math corpus and all 27 Pretext fixtures, generates symbol graphs, and performs
warning-clean DocC conversion. The visual-enabled product gate additionally
runs the offscreen AppKit RenderProbe.

The release preserves native SwiftUI block rendering, CoreText-painted
prepared-line inline rendering, stable streaming identity, sanitized native
rich HTML, safe policies, native selection, code highlighting, math, Mermaid,
attachments, and Pretext-backed layout.
