# SiriusMarkdown 0.6.29

This patch improves native macOS document selection and accessibility link actions. Policy-approved
painted and table links now report enabled, including document fragments.
Painted accessibility links use the same approved destinations as pointer links,
so denied source URLs do not expose an accessibility action.

Empty HTML ID anchors now reveal their document position even when they have no
selectable glyphs. The fallback adds no visible content or document height and
does not change selection. Mounted regressions cover empty paragraph and inline
anchors alongside existing distant-match and horizontal-overflow navigation.

Document selection uses system selection colors beneath crisp glyphs, extends
selected line endings, and joins adjacent prose without crossing table/list
columns. Rich HTML table selection follows actual padded cell geometry, including
spanning cells and tables without headers. The existing text surfaces and cached
layout are reused; no additional text hosts or per-drag shaping are introduced.

The change is generic and preserves the public API, host routing, Find placement,
source selection and rendering policies. Focused regressions cover enabled state,
external and fragment activation, denied destinations, link identity and bidi
geometry. Full product-gate evidence is recorded before publication.

Standalone RenderProbe pixel artifacts are not regenerated for this change.
