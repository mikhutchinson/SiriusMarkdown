# SiriusMarkdown 0.6.25

SiriusMarkdown 0.6.25 preserves the 0.6.24 narrow decorated-link repair and
calibrates its largest mounted release watchdogs to repeated exact-SHA results
from current GitHub-hosted Apple Silicon runners.

## Link rendering carried forward

- Fixed-width prepared leaves render the latest immutable inline layout after
  asynchronous favicon completion.
- CoreText line-plan reuse includes the complete prepared-content fingerprint.
- Link decoration, nonbreaking spacer, and the first label token remain one
  prepared wrapping unit.
- The automatic fallback is a font-relative decorative template SF Symbol;
  resolved branded favicons reuse its host and remain untinted.

## Hosted gate calibration

Two exact-SHA 0.6.24 runs measured 1.51–1.74 seconds in deferred SwiftUI graph
completion for the mounted 120-row/179 KB workloads. Explicit AppKit layout
remained 0.75–6.41 ms, table conversion/reuse/cache counters were identical,
and every semantic, mounted, and visual product regression passed. The broad
end-to-end watchdogs now allow 2.0 seconds. Their work-count, cache-reuse,
constraint-safety, and explicit-layout invariants are unchanged.

## Validation

The release gate discovers 954 Swift tests, builds a clean external SwiftPM
consumer, bundles all three demos, checks the 50-case math corpus and all 27
Pretext fixtures, generates symbol graphs, and performs warning-clean DocC
conversion. The visual-enabled product gate additionally runs the offscreen
AppKit RenderProbe.
