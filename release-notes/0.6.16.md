# SiriusMarkdown 0.6.16

SiriusMarkdown 0.6.16 fixes a JavaScriptCore lifetime violation in streamed
syntax highlighting. It preserves the complete native renderer and the bounded
streaming behavior introduced in 0.6.15.

## Fixed

- Highlight.js function, argument, and result values are now protected before
  they survive another JavaScriptCore allocation or move into Swift heap
  storage, and remain protected until the native bridge finishes consuming
  them.
- Runtime initialization protects each exported function immediately and
  releases partially initialized contexts safely on failure.
- The Mermaid JavaScript bridge now follows the same lifetime contract for its
  retained functions, arguments, and results.
- Runtime teardown unprotects retained functions before releasing the global
  context and context group.

## Evidence

- Deterministic Highlight.js and Mermaid tests force JavaScriptCore garbage
  collection at runtime initialization, argument handoff, invocation result,
  and result conversion boundaries.
- The forced-collection regressions pass under debug and optimized release
  code generation.
- The serial Swift release suite discovers 883 tests.

There is no WebKit fallback and no selection, syntax, math, Mermaid, table, or
attachment downgrade in this release.
