# SiriusMarkdown 0.6.6

SiriusMarkdown 0.6.6 adds block-level styling, atomic inline attachments,
broader native math coverage, and a substantial correctness and concurrency
hardening pass. The package remains native SwiftUI/CoreText: Markdown semantics
come from `swift-markdown`, expensive work stays in preparation, and no WebKit
renderer or default network image loader is introduced.

## Highlights

- Fourteen per-block style protocols plus `MarkdownDocumentStyle` let hosts
  replace prepared block chrome without changing parsing, layout, or cache
  identity. `MarkdownRendererConfiguration.gitHub` is a new opt-in
  GitHub-inspired theme/style preset; `.compactChat` and `.document` retain
  their existing defaults.
- Policy-allowed images now reserve atomic CoreText attachment boxes, preserve
  source-backed selection and outer-link hit regions, and mount one AppKit/UIKit
  host per prepared attachment. The default image policy still denies loading,
  and SiriusMarkdown performs no network fetch or image decode from SwiftUI
  `body`.
- A shared 50-case math/LaTeX corpus validates native SwiftMath rendering,
  original-source preservation, visual metrics, bounded cache reuse, and
  KaTeX/MathJax parity for the supported web subset.
- Generated LaTeX compatibility now covers more fraction, binomial, relation,
  arrow, array, matrix, and operator forms while preserving the original source
  used for copy and accessibility.

## Correctness and Safety

- Prepared cache identity now includes exact supplied measurements, run/source
  metadata, complete code fence info strings, render-relevant Mermaid theme
  values, exact math source, and attachment metrics/chrome.
- CoreText missing-glyph measurement uses native fallback shaping and applies
  semantic italic/monospace traits consistently across painting and document
  selection geometry.
- Math and attachment dimensions, scale, ascent/descent, and corner radii are
  finite and bounded before entering SwiftUI, CoreText, AppKit/UIKit frames, or
  layers.
- Vendored SwiftMath reverse maps, symbol registration, font/math-table state,
  display support, and spacing tables are immutable or synchronized for
  concurrent preparation.
- Public mutable SwiftMath atom models are canonicalized by runtime storage
  before copy/finalization. Malformed composites fail closed instead of
  force-casting, table cells finalize recursively, and negative table indices
  are ignored safely.
- `MTMathListBuilder.mathListToString` is non-mutating, preserves
  `color`/`textcolor`/`colorbox`, handles incomplete public models without
  trapping, and no longer carries a duplicate unsafe command parser.

## Validation

- 850 Swift tests across 17 suites.
- Focused AddressSanitizer and ThreadSanitizer runs for the new model,
  serializer, table, registry, and font-table paths.
- Clean local SwiftPM consumer resolution and build.
- Production builds and bundles for `MarkdownDemoApp`,
  `StreamingTranscriptDemo`, and `DocumentReaderDemo`.
- 50-case math corpus and 27 strict Pretext fixtures.
- Warning-clean symbol graph/DocC generation.
- Offscreen AppKit probes for document, chat, multilingual, inline attributes,
  overflow, code highlighting, hard breaks, resize containment, Mermaid, and
  native selection.

## Install

```swift
.package(
    url: "https://github.com/mikhutchinson/SiriusMarkdown.git",
    from: "0.6.6"
)
```
