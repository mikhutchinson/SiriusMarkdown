# Timed bug hunt — 2026-09-07

Baseline: published release 0.6.26, checkout `1a7a03b`. Work began at
21:45 UTC under a 15-minute limit. Three agents audited parser/source,
HTML/resources, and layout/rendering; the primary agent fixed recursive cache

## Implemented

- CR source mapping and streaming boundaries, including split CRLF handling;
  quoted CR/CRLF display-math normalization and inline newline byte offsets.
- Recursive sealed-state propagation through cached quotes, lists, and HTML.
- HTML code spacing, explicit repeated/trailing line breaks, nonbreaking and
  typographic spaces, and whitespace between nested inline elements.
- Isolation of internal Markdown placeholders from authored custom HTML tags.
- Cancellation of abandoned favicon response bodies and remaining-deadline
  limits for resource requests.
- Overflow-safe raw/prepared table spans and column inference, plus saturating
  ordered-list ordinals.
- Nonbreaking inline wrapping while retaining decoration/label grouping.

24 new named regression tests were added. Test discovery and the synchronized
release checklist now have a 990-test floor. Unreleased changes are recorded
in `changelog.md` and `bugfix.md`.
